# [Print GFG n times](https://www.geeksforgeeks.org/problems/print-gfg-n-times/1)
## Easy
Given a positive number n, print the string "GFG" exactly n times separated by a single space.Examples:Input: n = 5
Output: GFG GFG GFG GFG GFGExplanation: The string "GFG" is printed 5 times, with each instance separated by a space.Input: 3
Output: GFG GFG GFGExplanation: The string "GFG" is printed 3 times separated by spaces.
