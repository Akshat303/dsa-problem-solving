# [For-Each Loop](https://www.geeksforgeeks.org/problems/for-each-loop/1)
## Easy
Given an array of Strings&nbsp;arr[].&nbsp;Use For-Each loop to print each string in the array in a new line.
Examples:
Input: arr[] = [ "Hello", "World", "Geeks", "For", "Geeks" ]Output:HelloWorldGeeksForGeeksExplanation: All Strings of array are printed in a new line.
Input: arr[] = [ "Legends" ]Output:LegendsExplanation: Only string is printed in a new line.
