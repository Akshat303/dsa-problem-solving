# [Switch Statement](https://www.geeksforgeeks.org/problems/switch-statement/1)
## Easy
Given a number n, use a switch statement to print "Stop" if the given number is 1 (or Red light)"Standby" if the number is 2 (Yellow light)"Go" if the number is 3 (Green light). For any other number, print "Unknown" (without quotes).Examples:Input: n = 1
Output: StopInput: n = 2
Output: StandbyInput: n = 3
Output: GoInput: n = 4
Output: Unknown
